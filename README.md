# 🧠 Memory Game

A fun and interactive memory card game built with vanilla JavaScript. The player needs to remember the positions of the cards and match identical pairs before running out of available attempts.

## 🎮 How to Play

1. Enter your name to start the game.
2. Select the number of attempts or use the default setting.
3. Click on a card to flip it.
4. Try to find two matching cards.
5. If the cards match, they remain visible.
6. If they don't match, they will flip back.
7. Continue until all card pairs are matched.
